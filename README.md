# EnemyNameplateColors

A lightweight addon that colors enemy nameplates and cast bars based on unit type, threat status, and cast properties. Works exclusively in dungeons, raids, and scenarios.

## Features

- **Nameplate Colors**: Distinguishes bosses, mini-bosses, casters, and standard enemies with customizable colors
- **Threat-Based Coloring**: Different color schemes for tanks vs DPS/healers showing threat status at a glance
- **Cast Bar Colors**: Colors enemy casts based on type (standard, channeled, uninterruptible, important)
- **Interrupt Ready Border**: Green border appears around interruptible casts when your interrupt is off cooldown

## Usage

Type `/enc` to open the options panel and customize all colors.

## Requirements

- World of Warcraft: The War Within (11.x) or Midnight (12.x)
- Compatible with Blizzard's default nameplates

## Installation

1. Download and extract to your `World of Warcraft/_retail_/Interface/AddOns/` folder
2. Ensure the folder is named `EnemyNameplateColors`
3. Restart WoW or type `/reload`
